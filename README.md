# 综测雷达

每天北京时间 08:30 自动检查学校各部门、研究生创新实践大赛和地理/测绘相关学会网站上的新通知，挑出和综测加分有关的（课题申报、评优、志愿、竞赛、学术会议、征文、学生工作、奖助学金），标注大约对应哪一项、多少分，有新内容就发邮件。运行在 GitHub Actions 上，不需要服务器，电脑关机也照常运行。

## 一次性设置（约 10 分钟）

### 1. 开启 QQ 邮箱 SMTP，拿到授权码
QQ 邮箱网页版 → 设置 → 账号与安全 → 安全设置 → 开启"POP3/IMAP/SMTP服务" → 按提示生成**授权码**（一串 16 位字母，只显示一次，先复制下来）。

> 授权码相当于专用密码，只填在下一步的 GitHub Secrets 里，不要写进任何文件。

### 2. 把代码放到 GitHub 私有仓库
新建一个 **Private** 仓库（例如 `zongce-monitor`），把本文件夹全部内容上传。

### 3. 配置 Secrets
仓库页面 → Settings → Secrets and variables → Actions → New repository secret，添加：

| 名称 | 填什么 |
|---|---|
| `SMTP_USER` | 你的 QQ 邮箱，如 `123456@qq.com` |
| `SMTP_PASS` | 第 1 步的授权码 |
| `MAIL_TO` | 收件邮箱（可不填，默认发给自己） |

用 163 邮箱的话，再加一个 `SMTP_HOST` = `smtp.163.com`。

### 4. 手动跑一次试试
仓库 → Actions → 左侧"综测雷达" → Run workflow。约 1 分钟后去邮箱查收。第一封邮件会包含最近 3 周内的相关通知。

### 5. 微信提醒（可选）
微信 → 我 → 设置 → 通用 → 辅助功能 → QQ邮箱提醒 → 启用。新邮件会直接在微信里弹出。

## 日常使用
- 不用管它，有新通知才会收到邮件，没有就不发。
- 每月第一封邮件会附上"去年同月出现过的相关通知"，提醒你提前准备。
- 想加网站或调关键词：直接在 GitHub 网页上编辑 `config.yaml`。
- 如果某个网站连续 3 天抓不到，邮件里会有"抓取异常"提示。

## 本地运行（可选）
```bash
pip install -r requirements.txt
python monitor.py --dry-run          # 生成 out/digest.html 预览，不发邮件
python monitor.py --backfill 365     # 回溯一年，生成 out/timeline.html
```

## 说明
- 分值依据《西南大学地理科学学院全日制研究生综合考评实施细则》（西校地科院〔2022〕10号），最终以学院评审小组认定为准。
- 微信公众号、QQ 群里的通知抓不到，学院研会和团委的公众号仍需自己关注。
- 如果 GitHub 的海外服务器访问不了学校网站（邮件里会提示"所有网站都抓取失败"），可以改为在自己电脑上用 Windows 任务计划程序每天运行 `python monitor.py`。
